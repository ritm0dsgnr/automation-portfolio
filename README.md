# Дарья Перминова - Automation Portfolio

Публичные кейсы по прикладной автоматизации: Node.js-сервисы, парсинг, интеграции, мониторинг, обработка данных и AI/LLM-сценарии.

- [Открыть automation-портфолио](https://ritm0dsgnr.github.io/automation-portfolio/)
- [Frontend-проекты](https://ritm0dsgnr.github.io/frontend-portfolio/)
- [Репозиторий](https://github.com/ritm0dsgnr/automation-portfolio)

Репозиторий подготовлен как безопасная публичная витрина. В нём нет `.env`, токенов, рабочих дампов, приватных исходников, персональных данных и внутренней бизнес-информации.

## Моя роль

- разработка и поддержка прикладных сервисов на JavaScript / Node.js;
- browser automation и парсинг через Playwright / Puppeteer;
- интеграция API, webhooks, баз данных, CRM и облачных хранилищ;
- разработка ботов и внутренних инструментов;
- настройка cron-задач, очередей, мониторинга и уведомлений;
- внедрение AI/LLM-сценариев для анализа и структурирования данных;
- подготовка сервисов к запуску через PM2, Docker и CI/CD.

## Case Studies

### ContentOps Agent

**Задача:** автоматизировать контент-операции по карточкам задач и снизить ручную работу при изменении информации на сайте.

**Что сделано:**

- прием webhook-событий из Planka;
- постановка задач в очередь BullMQ;
- dry-run перед применением изменений;
- проверка риска изменений;
- комментарии в карточку и перевод между статусами;
- хранение артефактов и истории выполнения.

**Интеграции:** Planka, S3, MySQL, Telegram, сайт/админка.

**Стек:** TypeScript, Hono, BullMQ, Redis, S3, MySQL, Mastra, Zod.

**Результат:** рабочий контур для безопасной обработки контентных задач с проверкой перед применением.

### Map Parser

**Задача:** регулярно собирать данные об организациях и отзывах из картографических сервисов.

**Что сделано:**

- browser automation через Playwright;
- запуск задач по расписанию;
- очередь worker/scheduler;
- запись результатов в S3 и NocoDB;
- Telegram-уведомления об ошибках и статусах;
- проверки доступности парсеров.

**Интеграции:** S3, NocoDB, Telegram, карты/каталоги.

**Стек:** Node.js, Playwright, BullMQ, Redis, S3, NocoDB.

**Результат:** пайплайн регулярного сбора и проверки данных.

### HH Parser

**Задача:** автоматизировать сбор, сохранение и первичный анализ резюме.

**Что сделано:**

- поиск и обход страниц через Playwright;
- сохранение резюме в PDF, Markdown и JSON;
- загрузка файлов в S3;
- запись структурированных данных в NocoDB;
- LLM-анализ резюме;
- выгрузка контактов и результатов в Google Sheets.

**Интеграции:** HH, S3, NocoDB, Telegram, Google Sheets, LLM API.

**Стек:** Node.js, Playwright, S3, NocoDB, Google Sheets API, LLM.

**Результат:** рабочий контур для сбора и обработки резюме с последующей аналитикой.

### Sovameeting

**Задача:** автоматизировать обработку встреч и превращать транскрипты в полезные рабочие артефакты.

**Что сделано:**

- получение транскриптов;
- хранение raw-архива;
- генерация Markdown-версий;
- LLM-обработка встреч;
- подготовка писем/резюме;
- отправка в Telegram, Lark и Bitrix;
- синхронизация задач с Plane.

**Интеграции:** Fireflies, NocoDB, Telegram, Lark, Bitrix, Plane.

**Стек:** Python, FastAPI, httpx, Jinja2, NocoDB, LLM.

**Результат:** пайплайн, который превращает встречи в структурированные итоги и задачи.

### Analytics Agent

**Задача:** быстро получать отчеты по объектам на основе данных веб-аналитики.

**Что сделано:**

- прием ссылки на объект из чата;
- поиск объекта в NocoDB;
- запрос данных из Яндекс.Метрики;
- генерация отчета;
- отправка результата обратно в Lark.

**Интеграции:** Яндекс.Метрика API, NocoDB, Lark.

**Стек:** Node.js, Express, Puppeteer, Яндекс.Метрика API.

**Результат:** чат-агент для быстрых отчетов по объектам.

### Object Sync

**Задача:** синхронизировать объекты из разных источников в единую таблицу.

**Что сделано:**

- сбор данных из нескольких источников;
- кластеризация по координатам;
- проверка похожести названий;
- защита от ошибочной склейки объектов;
- запись результатов в NocoDB;
- ежедневный cron-запуск.

**Интеграции:** NocoDB, PostgreSQL, S3.

**Стек:** Node.js, PostgreSQL, node-cron, NocoDB.

**Результат:** единая таблица объектов с регулярным обновлением.

### Autotests & Monitoring

**Задача:** отслеживать доступность, SSL и производительность сайтов.

**Что сделано:**

- проверки HTTP-статуса;
- проверки SSL-сертификатов;
- замер LCP, TTFB, TBT и других метрик;
- запуск по расписанию;
- уведомления только при ошибках.

**Интеграции:** Telegram, сайты, CI/CD.

**Стек:** TypeScript, Playwright, Node.js, cron.

**Результат:** мониторинг, который помогает быстро замечать проблемы на сайтах.
